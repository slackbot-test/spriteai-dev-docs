# Sprite Generation Documentation Overview

## Introduction
Welcome to the documentation for our sprite generation module. This overview provides quick access to various categories of sprite generation functionalities.

## Categories

### General Sprite Generation
- [generateSprite](./generateSprite.md): Create custom sprite images based on text descriptions.

### Isometric Sprite Generation
- [generateIsometric](./generateIsometric.md): Generate isometric-style sprite images for objects or characters.

### Animated Sprite Generation
- [generateAnimatedSprite](./generateAnimatedSprite.md): Create animated sprite sequences from text descriptions.

### Sprite Manipulation
- [resizeSprite](./resizeSprite.md): Resize existing sprite images to desired dimensions.
- [rotateSprite](./rotateSprite.md): Rotate sprite images to specified angles.

### Utility Functions
- [getSpriteInfo](./getSpriteInfo.md): Retrieve metadata and information about sprite images.
